🌐 IPv6

From IPv4 to 128-Bit Next-Gen Networking

The Problem: Why IPv6?

Old World: IPv4 Limits

4.3 Billion

Total addresses globally. We ran out in 2011. Every phone, smart TV, and IoT device needs an IP.

New World: IPv6 Scale

340 Undecillion

2¹²⁸ total addresses. That is 340,282,366,920,938,463,463,374,607,431,768,211,456. Enough for every atom on Earth's surface.

NAT Was Only a Temporary Band-Aid 🩹

In IPv4, we survived exhaustion by using NAT (Network Address Translation). Your entire home shares ONE public IPv4 address, and your router hands out fake private IPs (like 192.168.1.5) to your devices.


The IPv6 Paradigm Shift: True End-to-End Connectivity

Because IPv6 has nearly infinite addresses, NAT is no longer required! Every single device on your network can get its own Globally Unique address. This restores the Internet to its original design: devices communicating directly end-to-end, which improves speed, security (IPsec is built-in), and peer-to-peer applications like VoIP and gaming.

Fundamental Structure of an IPv6 Address

2001:0DB8:0000:0000:0000:FF00:0042:8329

Length

128 Bits total.

Format

Hexadecimal (0-9 and A-F). Case-insensitive.

Segments

8 "Hextets" separated by colons (:). No periods.

What is a "Hextet"?

In IPv4, we use 8-bit "Octets". In IPv6, we group numbers into 16-bit blocks called Hextets (or quartets).

  • 1 Hexadecimal Character = 4 binary bits
  • 4 Hex Characters per Hextet = 16 binary bits
  • 8 Hextets × 16 bits = 128 total bits

Binary Breakdown Example (Hextet 1):

2 = 0010
0 = 0000
0 = 0000
1 = 0001
Result = 0010 0000 0000 0001 (16 bits)

Address Simplification Rules

Writing out 32 characters is tedious. Network engineers use two strict rules to compress addresses.

Rule 1: Omit Leading Zeros

Within any hextet, you can drop the zeros at the front.
0DB8 → DB8
0042 → 42
0000 → 0

Rule 2: Double Colon (::)

You can replace one contiguous block of all-zero hextets with a double colon ::.
CRITICAL: You can only use :: ONCE per address!

The /64 Split: Network vs Interface

The Standard /64 Prefix

In IPv6, the standard subnet mask for end-user networks is almost always /64. It splits the massive 128-bit address exactly in half.

First 64 Bits: Network Prefix
Last 64 Bits: Interface ID (Host)

Network Prefix (Left 64)

Usually made up of:

  • Global Routing Prefix: Assigned by your ISP (often a /48 block)
  • Subnet ID: 16 bits you use to create 65,536 internal subnets.

Interface ID (Right 64)

Identifies the exact physical device. This can be:

  • Automatically generated from the MAC address (EUI-64)
  • Randomized for privacy (Privacy Extensions)
  • Manually assigned statically.

EUI-64: Auto-Generating the Interface ID

EUI-64 is a method where a device automatically generates its own 64-bit Interface ID by mathematically altering its 48-bit MAC address. Because MAC addresses are globally unique, the resulting IPv6 host ID is globally unique.

Step 1: Split the 48-bit MAC address directly in half.
Step 2: Insert the 16-bit hex value FFFE into the exact middle.
Step 3: Convert the first byte to binary and invert the 7th bit (Universal/Local bit).

Core IPv6 Address Types

Type Prefix / Range Description / IPv4 Equivalent
Global Unicast 2000::/3 Globally unique, routable on the public Internet. Replaces Public IPv4 addresses. (Starts with 2 or 3).
Link-Local FE80::/10 Auto-configured on EVERY interface. Only routable on the local subnet. Routers will drop these packets. Replaces APIPA (169.254.x.x).
Multicast FF00::/8 One-to-many communication. Replaces IPv4 Broadcasts (which no longer exist in IPv6).
FF02::1 = All Nodes, FF02::2 = All Routers.
Loopback ::1/128 Used by a device to send traffic to itself for testing. Equivalent to IPv4 127.0.0.1.
Unspecified ::/128 All zeros. Used exclusively as a source address when a device is booting up and requesting an IP via DHCPv6. Equivalent to 0.0.0.0.

Knowledge Check

1. Compress this address: 2001:0000:0000:0000:000A:0000:0000:0001
2001::A:0:0:1

Explanation: We apply the `::` to the longest stretch of zeros (the first 3 zero hextets). The second set of zeros must be written as 0:0 to avoid using `::` twice. Leading zeros in 000A become A.
2. What type of IPv6 address is FE80::1?
Link-Local Address

Explanation: Any address starting with FE80 is Link-Local, meaning it is only valid for communication on the local network segment.
3. What is the standard network prefix size for an end-user IPv6 subnet?
/64

Explanation: A /64 leaves exactly 64 bits for the Interface ID, which is required for SLAAC and EUI-64 auto-configuration to function correctly.
4. Why does IPv6 eliminate the need for NAT?
With 340 undecillion possible addresses, every device on Earth can have its own Global Unicast Address. We no longer need to "hide" private devices behind a single public router IP.
