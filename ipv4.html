Anatomy of an IPv4 Address

An IPv4 address is fundamentally a 32-bit binary number. To make it readable, we divide these 32 bits into four 8-bit groups called Octets. We convert each octet into a decimal number (0-255).

IP Classes & The "Minus 2" Rule

The Minus 2 Rule ($2^h - 2$)

When calculating usable hosts, we subtract 2 addresses:

  • Network ID (All Host bits = 0): Identifies the network itself (e.g. 192.168.1.0).
  • Broadcast IP (All Host bits = 1): Used to shout to all devices (e.g. 192.168.1.255).

Private IPs & NAT

Because IPv4 has limited addresses, RFC 1918 created Private IP ranges. These cannot be routed on the internet. NAT (Network Address Translation) translates your Private IP to your router's Public IP.

Mask Theory & Mathematics

1. What is a Subnet Mask?

A Subnet Mask is a 32-bit number that masks an IP address. It tells the device exactly which part of the IP is the Network (represented by binary 1s) and which part is the Host (represented by binary 0s). If a PC wants to send a packet, it checks the mask to see if the destination is on the local network. If not, it sends it to the default gateway (router).

CIDR /24 = 11111111.11111111.11111111.00000000 = 255.255.255.0

2. What is a Wildcard Mask?

A Wildcard Mask is the exact inverse of a subnet mask. In a wildcard mask, 0 means "must match exactly" and 1 means "don't care". It is heavily used in Cisco Access Control Lists (ACLs) and routing protocols like OSPF to match IP ranges.

How to Calculate: Subtract the subnet mask from 255.255.255.255.

255.255.255.255
- 255.255.255.0 (Subnet Mask)
------------------
0 . 0 . 0 . 255 (Wildcard Mask)

3. Binary AND / OR Logic

Routers are just calculators. To find the Network Address, the router takes the IP and the Subnet Mask and performs a bitwise AND operation (1 AND 1 = 1. Everything else = 0).

To find the Broadcast Address, it takes the Network Address and performs a bitwise OR operation with the Wildcard Mask.

Routing & Longest-Prefix Match

Routers compare a destination IP against their known prefixes. If multiple routes match, the router ALWAYS chooses the most specific matching route. This is the Longest-Prefix Match (LPM) rule. A `/24` beats a `/16`.
